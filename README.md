# 🚀 Career Guide

An AI-powered career coaching application built to help users discover suitable career paths and get personalized learning and job guidance.

---

## 🌟 About the Project

**Career Guide AI** was developed as part of a **Generative AI Hackathon**, where our team built an intelligent assistant that helps users make informed career decisions.

The application acts as a virtual career coach by analyzing user inputs and providing structured, actionable guidance.

### 🏆 Ranked Top 10 in the Hackathon

---

## 💡 Key Features

- 🔍 **Career recommendations** with salary insights and market demand  
- 🧭 **Personalized learning roadmaps** (Beginner → Advanced)  
- 🎥 Curated **YouTube tutorials**  
- 📚 **Online course recommendations** (Coursera, Udemy, edX)  
- 💼 Relevant **job search links**  
- 📄 **Downloadable career plan (PDF)**  

---

## 🛠️ Tech Stack

- 🧠 **Groq API (LLaMA 3)** – AI-powered career reasoning  
- 💬 **Streamlit** – Interactive web interface  
- 📺 **YouTube Data API** – Tutorial recommendations  
- 📥 **PDFKit / wkhtmltopdf** – Career plan export  
- 🤗 **Hugging Face Spaces** – Deployment 

---

## 🚀 How It Works

1. Enter your **education, interests, skills, and preferences**
2. Receive **3 career path suggestions** with salary and demand insights
3. Select a career to explore:
   - 📍 Step-by-step learning roadmap  
   - 🎥 YouTube tutorials  
   - 📚 Courses from trusted platforms  
   - 💼 Job search links  
4. 📄 Download a **complete career plan as a PDF**
